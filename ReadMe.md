# Employee Task Management

A Full Stack Employee Task Management System built using ASP.NET Core 8 Web API, Angular and SQL Server.

## Technology Stack

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- Angular
- JWT Authentication

frontend/
